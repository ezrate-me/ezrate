# EZRate

**قیمت واقعی دلار، طلا، سکه و ارز دیجیتال در بازار آزاد ایران — API، ویجت و افزونهٔ وردپرس**

**Iran's real free-market rates — dollar, gold, coins and crypto — as an API, widgets and a WordPress plugin**

[ezrate.me](https://ezrate.me/fa) · [API](https://ezrate.me/api/fa) · [ویجت](https://ezrate.me/services/widgets/fa) · [English](https://ezrate.me/en)

### 🧩 پروژه‌ها

| مخزن | چیست |
|---|---|
| **[ezrate-api](https://github.com/ezrate-me/ezrate-api)** | API قیمت ارز، طلا، سکه و تتر (وب‌سرویس REST با خروجی JSON)، نمونه‌کد PHP، JS و Python |
| **[ezrate-widgets](https://github.com/ezrate-me/ezrate-widgets)** | ویجت قیمت ارز و طلا برای هر سایت با یک خط کد، بدون کلید API |
| **[ezrate-wordpress](https://github.com/ezrate-me/ezrate-wordpress)** | افزونهٔ وردپرس: تیکر، کارت، جدول و نمودار قیمت |

### 🚀 شروع رایگان

در [ezrate.me](https://ezrate.me/auth/register/fa) ثبت‌نام کنید (رایگان)، از پنل کاربری کلید API یا ویجت بسازید و در چند دقیقه قیمت‌ها را در سایت یا اپ خود داشته باشید.
